## Constitution - governing principles

> Inherited by every spec. Immutable unless explicitly decided otherwise.

1. **The model proposes, the harness decides.** Anything that can be verified by code leaves the prompt and becomes an executable rule.
2. **The spec lives in the code.** Each contract is a @Spec/@AC annotation on the symbol it governs - not a loose file.
3. **Verification is deterministic.** spec-lint, traceability and invariants are a pure function of (code, annotation); no LLM.
4. **Scope is law.** The agent only touches allowedFiles; everything else is blocked before it happens.
5. **Done is when the criteria pass.** No @AC without a test; the acceptance gate won't release the stop while any of them fails.
